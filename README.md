# Cash Flow Radar

Демонстрационное приложение для прогноза денежных потоков ремонтного предприятия. Прогноз на 30, 90 и 180 дней, платёжный календарь, дебиторская задолженность, сценарный анализ и трёхцветный радар ликвидности.

Все данные вымышлены. Красный сигнал включается, если хотя бы в один день выбранного горизонта прогнозный остаток отрицателен.
